About Movie Explorer

Front-End Architecture & Academic Overview

Movie Explorer is a front-end movie discovery and ticketing web application inspired by commercial cinema platforms like BookMyShow. Built completely using standard HTML5, CSS3, and modern JavaScript with zero external libraries or backend frameworks, it showcases responsive design, DOM manipulation, multi-criteria filtering, and simulated seat reservation workflows.

🔎 Instant Search & Filters

Real-time title searching combined with language/genre chips and multi-criteria non-destructive sorting.

💺 Cinema & Seat Booking Flow

Interactive theatre seat matrix featuring tier categorisation (Regular and Premium at the back) and dynamic price calculation.

📱 100% Responsive UI

Mobile-optimized horizontal poster tracks, compact navigation, and accessible keyboard focus states.
